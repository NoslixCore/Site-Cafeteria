# ☕ Cafe Delight

## Sobre o projeto

O Cafe Delight é um site desenvolvido para representar uma cafeteria. O projeto apresenta informações sobre o estabelecimento e cardápio.

O objetivo é criar um site simples, organizado e fácil de utilizar.

## Funcionalidades

- Página inicial com apresentação da cafeteria.
- Página de cardápio com produtos e preços.
- Navegação entre as páginas.
- Botões para aumentar e diminuir o tamanho da fonte.
- Recursos de acessibilidade.
- Layout adaptável para celulares e computadores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
